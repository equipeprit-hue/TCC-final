# Kora — TCC-final

Plataforma de saúde e bem-estar desenvolvida como projeto de Trabalho de Conclusão de Curso.

## Instalação

Para instalar as dependências do backend, entre na pasta `backend` e execute:

```bash
npm install
```

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express

## Projeto

Desenvolvido para incentivar hábitos saudáveis por meio de atividades físicas e gamificação.
